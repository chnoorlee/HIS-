## 本轮自评与改进

本轮以医生能否发现并处理错误、数据故障时状态是否可信为优先级。

| 发现的问题 | 已实现的改进 | 验证与限制 |
| --- | --- | --- |
| 普通保存可能将旧正文引用自动推进至新事实版本 | 按章节保存事实快照，逐章显式核对，核对提交执行版本比较 | 普通保存、跨章引用、并发更正回归通过；系统不能证明医生文本与事实语义一致 |
| 文书生成后新增的重要事实可能漏入审核 | 适用的新事实必须纳入章节或说明原因排除；空白及过短理由拒绝 | 覆盖迟到过敏史、已确认但未纳入事实和旧审核导出阻断 |
| 引文截取可能丢失同句的否定、停药或主体上下文 | 抽取契约 1.1 要求完整句子或话轮，非法结果整批拒绝 | 否定、分号、剂量小数及时间回归通过；未证明模型完全理解语义或跨句上下文 |
| 麦克风中断后仍可能显示可恢复或完整结束 | 浏览器输入故障锁定，保留待处理分片，阻止虚假恢复和完成 | 受控媒体轨道 ended/mute/失效回归通过；实体麦克风拔插待验收 |
| 原生上传故障被误显示为采集暂停，音量质量不可见 | 采集状态以原生端事件为准；医生/患者声道分别显示电平、持续低电平、削波和数据过期 | 合成桥事件及桌面/移动布局验证通过；电平不等于 ASR 置信度或降噪效果 |
| 长篇章节定位困难、切换文书可能丢失修改 | 章节导航、缺项定位、随宽度调整的正文高度、保存/放弃/继续编辑对话框 | 取消切换、保存失败保留编辑、保存后继续及手机布局通过 |
| 新引用发生冲突后重试或编辑正文可能丢失核对版本 | 保留已见版本直到重新核对；显式重载服务端版本时清除已放弃暂存 | 连续三次冲突重试、修改正文、重新核对及同版本重载回归通过 |
| 错误提示遮住手机端弹窗操作 | 根据实际提示高度为弹窗预留空间 | 错误状态下校验弹窗、按钮和提示边界，更新截图已目视检查 |

引用核对请求、旧数据兼容与处理流程见 [文书引用核对](reference-review.md)，抽取规则见 [抽取契约](extraction-contract.md)。

## 医院上线前的输入

需要批准的 ASR/LLM 地址和凭据、医院 OIDC 配置、EMR/HIS 接口契约、科室模板及授权的音频金标准。真实双麦、噪声、方言/否定词、长录音、网络故障、安全部署和备份恢复应按试点方案分别验收。

当前版本恢复隔离后始终关闭自动写回；解除流程需完成整个 EMR 恢复窗口核查和院方连接器验收，普通开关不能绕过。步骤见 `docs/operations.md`。
